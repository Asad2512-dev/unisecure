# Analytics

`/admin/reports/analytics` shows database-backed active people, enrollments, sessions, security transactions, attendance status totals and notification delivery states for a date range. These are counts, not estimates of current campus presence or proof of push receipt. Empty data is shown as empty rather than fabricated.

Session and attendance analytics include finalized, non-cancelled sessions only. Date filters are inclusive on both boundaries. The verification suite covers populated, cancelled, unfinalized and empty datasets.
